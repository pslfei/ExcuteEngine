# 回归设计

Program.cs 调用实际 InfluxDBHelp 公开入口，不复制产品的序列化和分流实现。FakeServer.cs 捕获 HTTP 路径、请求头与原始正文，并按队列响应或延迟发送响应头/正文，分别验证发送与读取时限。

两个相互独立的本地服务代表旧 InfluxDB/查询代理与新 TSQSERVER。HTTP 模式全过程检查旧服务无请求，包含失败路径；切回旧模式后检查 SDK 发出的实际请求。测试之间顺序安排，避免静态初始化方式与响应队列相互干扰。

仅反射访问私有模式字段及内部 HTTP 状态适配器，用于核对模式和恢复状态，不向产品增加测试专用公开方法。LA 样本不运行算法构造；结束时恢复配置、客户端、超时、模式和线程数值区域设置，停止并释放本地服务。

边界测试检查整批预校验发生在第一次发送前，以及拆批时间戳一致；HTTP 模式禁止自动重定向写入、应用层重试和失败回退，不把部分成功表述为整批事务。
